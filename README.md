# UTSAV ADHIKARI — PERSONAL PORTFOLIO

**Student • AI Enthusiast • Cloud Explorer • Cybersecurity Explorer**

A modern personal portfolio website built with **HTML, CSS, and JavaScript** to showcase my technical skills, projects, certifications, problem-solving progress, and learning journey.

The website features a dark glassmorphism-inspired interface with animated statistics, interactive skill levels, smooth navigation, a typewriter effect, responsive layouts, custom cursor effects, scroll animations, and a functional contact form.
